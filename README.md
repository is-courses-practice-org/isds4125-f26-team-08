# Red Stick Reader

The website for Red Stick Reader, an independent bookshop on 5120 Plank Road in
Baton Rouge.

This repository is the working copy for the ISDS 4125 team Git exercise. Your
team has write access to it. Everything you change here is shared with your
teammates, which is the entire point.

## What is in here

| File | What it is |
|---|---|
| `index.html` | The home page. Carries the high-level sections and the featured cards. |
| `staff-picks.html` | Books the staff recommend. |
| `events.html` | Readings, signings, poetry night. |
| `book-clubs.html` | The shop's four reading groups. |
| `new-arrivals.html` | What came in this week. |
| `visit.html` | Hours, directions, parking. |
| `styles.css` | The shared stylesheet. Every page links to it. Do not edit it today. |
| `snippets.txt` | Every piece of HTML you need for the exercise. Copy from here. |

## How to look at the site

Open `index.html` in a browser. There is no build step, no server and no
dependencies — it is plain HTML and one stylesheet, exactly like the personal
website you built individually.

## The rules for today

- Never run `git push --force`.
- Always commit before you pull.
- Always use `git commit -m "your message"`.
- When you resolve a conflict, keep everybody's work — not just your own.
- If you get stuck, delete your folder and clone again. Everything pushed is
  safe here.

The full instructions are in the handout.
